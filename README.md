# 启动与运行说明

本项目为纯静态站点，无需后端服务，可通过以下方式在不同设备上运行。

## 1. PC 端启动

在项目根目录下，指定一个当前未被占用的端口号（例如 `8000`），启动本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

启动后：

- 在本机浏览器中访问 `http://localhost:8000` 即可打开项目。
- 在同一 WiFi 下的其他终端（手机、平板等）浏览器中，访问 `http://<本机IP>:8000` 即可打开项目。

> 提示：若 `8000` 端口已被占用，可更换为其他未占用端口，例如 `python3 -m http.server 8080`。

## 2. iPad 启动

1. 将项目打包（压缩为 zip 等格式）。
2. 将打包文件发送到 iPad。
3. 在 iPad 上安装 **WorldWideWeb** 工具。
4. 使用 WorldWideWeb 打开打包后的项目即可运行。

## 3. 安卓平板

目前尚未验证成功。需要在社区中寻找与 iPad 端 **WorldWideWeb** 对标的本地站点运行工具。

## 4. 鸿蒙平板

目前没有相关的本地站点应用可支持运行本项目。
